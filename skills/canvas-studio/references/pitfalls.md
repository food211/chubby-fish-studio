# 硬约束与踩过的坑

这些是重画过才总结出来的，开新画之前扫一眼能省一次返工。

## 物理约束（改不了）

- **水彩白压深色永远是灰的**，刷多少遍都白不回来；把湿度降到 20 只会让它斑驳。要纯白就换 `circle` / `flat` / `soft`。
- 反过来，`circle` / `flat` / `soft` **做不出湿画的水味**：它们是实色，没有洇和湿边。
- 水彩只沉积约一半颜料，尺寸越大越淡；要浓靠**多刷几层**，不是拉湿度。
- 尺寸：`watercolor`/`dry`/`splatter` 约 2×size，其它约 1×size。

## 作画顺序

- **先背景，再主体**。主体已经画上去之后再回头重刷背景，会把主体洗淡。
- 远的先画、近的后画，重叠关系靠覆盖顺序解决。
- 大面积先铺、轮廓后压、细节和高光最后。
- 收尖不要手写压感数组：`taper: "out"` 就够；但低压力**同时**变细和变淡，画粗壮的造型不要用它起稿——先用满压力立形，再补尖端。

## 常见翻车

- **白色小点会被读成洞**：浅色背景上画纯白圆点，看起来像纸挖了个洞。要"高光"就用浅蓝/浅青，别用纯白，或者外面加深色一圈。
- **高光不够亮就是没画**：浓度 55~62 与周围只差 1~4 个色阶，等于没画。高光用 85~90，必要时先压暗一圈再提亮。
- **用肤色盖回眼线**会把眼睛上缘切平，看着眯眼——宁可从整只眼睛重画。
- **头发别用 `ellipse` + `ring` 当底**：环的内边缘是正椭圆，脸会被框成 U 形、显小。先定脸的大小，再用 `path` + `fill` 沿脸轮廓往外描一圈发形。
- **路径坐标要全在 0–1**（或最多 1.25）：越界值现在会被夹回边上，但早期版本会把整条路径当像素读，笔触落在左上角看不见。
- **撤销之后一定要重新 glance**：撤销会改变画面，守卫会拒绝下一笔。
- **清空是不可逆的用户决定**：不要为了自己方便清空用户的画，先问。

## 关于重画

叠太多层、形状已经糊掉的时候，**重画往往比打补丁快**。但重画意味着清空，得先得到用户同意；同意后从背景开始一气画下去，别在原稿上一点点救。

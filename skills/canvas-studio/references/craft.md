# 画法：从大形到收笔

## 构图与体块

- 缩略图用来定**剪影、焦点、最大的几块颜色**。同一种色相里，几个清楚分开的明度就足以撑起形状。
- 进大形时先标几个点：两端、最宽处、转向的位置；再用长线把它们连起来，拐角和缺口别磨平。
- 先铺一个平的剪影，比一堆横排笔画更容易判断倾斜、宽度、缝隙；在边界内填充，轮廓比"用排线的端点去凑"干净得多。
- 面转折、褶皱、交叠的地方，**一块亮面加一块暗面**通常就够了；一个连续的平面可以只有一个颜色。

## 分层与光

- 从远的往近的画，交叠关系自然就对了。底色可以铺到后面的形状底下；绕着留出一道缝，就能保住一条纸白或高光。
- 先定一个主光方向，高光和暗部都跟着它走。投影要有，它让人读出"贴着地"还是"抬起来了"。
- 暗部可以当成一个独立形状来画：`circle`/`flat` 给硬边，`soft` 给渐变边。

## 选笔与落笔

- `circle`/`flat` 出硬边实色，`soft` 是实芯带晕边，`watercolor` 给大块氛围和湿边，`splatter` 撒颗粒，`dry` 出飞白。
- 小尺寸 `flat` + 间距 1 + 浓度 75–90，是铅笔线。
- 涂抹可以当手指用：短距离混两色，长距离拖出方向感；贴近轮廓时用小笔头，别把形糊掉。
- 手绘感来自**方向、压力、重复笔的节奏**，不只是轮廓抖动：长线加 0.5–1.5px 的 `jitter` 就够，小高光、精确接缝用 0。
- 同一组笔触共享方向、略变长度和间距，比等距平行线自然。

## 自检

- 先 glance：几块大色块能不能合起来读成你要的东西，焦点是不是跑偏。
- 再看 zoom：一条边、一只眼、一处颜色过渡；有问题就只改那一块。
- 如果一块地方看着"乱"，通常是色太多或细节太碎，不是不够细：收窄颜色、把细节画少一点。形状在这个尺度已经读得出来，就不用再加笔了。

# 画法：从大形到收笔

## 新作品先看草稿

先用几笔长线或两三块明暗，把最值得商量的地方画出来。人物可以先定朝向、姿势和头身比；风景可以先定地平线、主体的位置和留白。缩小看也能读懂构图，就可以把画布给用户看，问一句具体的问题，例如“桥放在这里，前景的水面够宽吗？”问完先停笔，等用户反馈。

收到意见后，建议直接在这张草稿上改，让用户看得出哪儿变了。等用户说满意或示意可以画正式稿，再用 `canvas_look` 留下定稿的完整画面作为参考。确认可以清空当前画布后，从空白处重新起正式稿，参考草稿里已经定好的构图、比例和动态，把细节和笔触留到这一遍展开。

## 人物参考图怎么看

起人物草稿时，可以把参考图和画布想成并排的两张纸。先看整个人，再看脸，最后挑两三个最影响相似度的关系回头比一遍。

1. **缩小看剪影。** 找头顶、下巴和肩端，看看头往哪边偏、肩线往哪边斜。画全身时，可以用头顶到下巴作一把尺，看看肩宽相当于几个头宽、全身约有几个头高。蓬松的头发、角和头饰另外估，它们会把头的轮廓撑大。
2. **给头找朝向。** 先概括颅顶、颧部最宽处和下颌转角，再想象一条从眉心沿鼻梁到下巴的中线，以及一条绕过双眼的横线。四分之三侧脸尤其值得比：中线两边各露出多宽的脸，远眼露出多少，鼻梁遮住了哪一段内眼角？仰俯时也看鼻底和下巴底面露出多少。
3. **用图里的尺度量五官。** 正脸可以借一只眼从内眼角到外眼角的宽度，估两眼之间能放几只眼，再比眼尾到脸缘还剩多少。纵向先标眉线、鼻底、嘴缝和下巴，比较眉到鼻底与鼻底到下巴哪段长，再看嘴缝把后一段分成怎样的上下两截。“三庭五眼”适合用来提问，具体距离以眼前这张脸为准；二次元的大眼、短鼻、小下巴尤其值得单独量。
4. **用对齐、角度和空隙复核。** 想象从内眼角垂下一条线，看看鼻翼落在线的哪边；再看两眼角的连线和嘴角连线各斜多少。遇到侧脸，可以把注意力移到鼻尖、唇峰、下巴前面那块空白，它的折线常比盯着鼻子更容易看出嘴画凸了还是下巴缩进了。
5. **趁草稿还简，找出最大的一处偏差。** 把草稿和参考图里的头看成同样高，来回对看。比如眼睛单看都像，整张脸却显宽，可以先比眼距和两侧脸颊留白，再决定挪眼睛还是收轮廓。眯眼看一眼发际、眼窝和下颌下方的明暗大块，最后再补睫毛、发丝和饰品。

如果任务是把正常身高的设定改画成低头身角色，可以有意放大头、缩短四肢，同时从参考图里选两三处辨识度最高的关系带进新比例，例如微垂的眼尾、宽眼距、刘海缺口正对哪只眼。多视图先选最接近目标角度的一张量脸，其余视图用来确认耳朵、角和发饰的前后位置。

## 如何画出好的作品

先用形状、明度和色彩定画面，再按用户要的效果选择落笔方式。草稿里可以先试画主体的一小块，看看希望看到的是笔触的叠压，还是色块和线条的清晰交界。

### 形状（Shape）

- **先找走势和松紧。** 看形体朝哪边伸展、哪里最宽、到哪里开始收，再看相邻物体之间的空隙是什么形状。比如一缕头发，发根贴着头，外侧先鼓起来，内侧收得紧一些，两侧到了发梢才合拢。
- **用少量长弧和短转折概括。** 用 `path` 配合 `fill: true` 铺自然形体时，建议避开标准圆、均匀波浪和无意的镜像对称。先在最宽处、转向处和遮挡处安排少量端点，曲线的控制点随该段的方向和弯度调整。画翅膀时，靠翼根的膜可以宽而浅，靠翼尖的膜可以窄而深，缺口随翼骨的位置改变。
- **缩小看剪影。** 用 `canvas_glance` 检查形体的方向、鼓起和收拢是否清楚。轮廓太规整时，可以先调整弧度、宽窄和转折位置。

### 明度（Value）

- **把亮暗先归成大块。** 草稿可以先分亮、暗两组，有需要再补中间调。相邻的暗面可以并作一块，省下遮挡处以外的细线。用 `canvas_glance` 看明暗分组能否托住主体，最清楚的边缘是否出现在想让人先看的地方。
- **按边缘的作用选笔。** 需要看清交叠时，可以用圆头笔或平头笔画出清楚的边。转面渐暗时，可以用柔边笔过渡。白头发迎光处可以融进浅背景，只在发束转暗或互相遮挡的地方留一段清楚的边。

### 色彩（Color）

- **想清楚这一笔要改什么。** 设 `color` 前，可以先决定要偏什么色、亮暗变多少、要更鲜还是更灰。比如给灰紫翅膀加一点偏蓝的反光，可以先选明度接近的蓝紫，让它仍然读在同一片暗面里。可以先试一小笔，用 `canvas_zoom` 看它和邻色接起来的效果。
- **续色时看画布上实际留下的颜色。** 柔和衔接时，可以用 `canvas_sample` 取混色后的像素，再按需要微调颜色。相邻色块接近时，边缘可以放松一些，把更明显的色彩差异留在需要引导视线的位置。

自然形体的主线、明暗分组和色彩关系可参阅 [Ruskin《The Elements of Drawing》](https://www.gutenberg.org/cache/epub/30325/pg30325-images.html) 与 [Dow《Composition》](https://library.wrkhrs.co/texts/dow-composition/dow-composition.html)。

### 手绘感

- **让笔触顺着体块走。** 可以用宽笔铺大形，让相邻几笔略有重叠，并顺着曲面改变方向、长度和间距。用 `points` 的 `[x, y, pressure]` 配合 `usePressure: true`，试试轻起、压实、轻收。油画感可以保留宽笔的叠压，水彩感可以留几道纸白，让某些湿边自然洇开。
- **挑几段留出笔迹。** 如果先用闭合路径铺底，可以用压感笔沿走势续出几段边缘。比如顺着发束轻扫两三笔，其他地方让较长的弧线保持完整。用 `canvas_glance` 检查笔触缩小后是否还跟着形体走。

### 干净插画

- **给轮廓两侧各找一个作用。** 写闭合 `path` 前，可以先判断哪一侧该绷紧、贴住或支撑，哪一侧该鼓起、弯折或甩出去。绷紧的一侧可以用 `l` 或浅弧，鼓起的一侧可以用长弧，转折点放在方向真正变化的位置。比如一束向右甩的头发，外侧用长弧带出动势，内侧先沿脸颊走一段较平的边，再在发梢收拢。先用 `fill: true` 铺成单色，用 `canvas_glance` 检查单看剪影时是否还读得出方向，发束和脸颊间的空隙是否清楚。
- **让阴影也有自己的形状。** 赛璐璐式明暗可以先画一个底色，再加一块沿形体转折的阴影。相邻色块已经能分开时，可以让色差直接交代边缘。
- **挑几段画线。** 交叠或遮挡处可以用压感笔画得实一点，顺着轮廓逐渐收轻，在亮侧留一段空。比如刘海压住额头的位置可以画实，发梢轻收，发顶靠色差接背景。确实需要整圈描边时，可以用同一笔的 `outline` 对齐填色。
- **看缩略图，再查接缝。** 用 `canvas_glance` 看线条和硬边是否集中在需要看清的地方。若每块色都像套了同样粗的边，可以少描几段，保留有用的转折线。再用 `canvas_zoom` 检查焦点附近的漏白和重边。想兼顾两种效果时，可以用干净色块稳住大形，把可见笔触留在需要表现质感的局部。

直边与曲边的观察可参阅 [Mattesi《Force: Character Design from Life Drawing》第三章](https://www.oreilly.com/library/view/force-character-design/9780240809939/xhtml/ch03.xhtml) 与 [Stanchfield《Drawn to Life》第 19 页](https://api.pageplace.de/preview/DT0400.9781136138386_A23813070/preview-9781136138386_A23813070.pdf#page=38)。

## 分层与光

- 从远的往近的画，交叠关系自然就对了。底色可以铺到后面的形状底下；绕着留出一道缝，就能保住一条纸白或高光。
- 先定一个主光方向，高光和暗部都跟着它走。投影要有，它让人读出"贴着地"还是"抬起来了"。

## 选笔与落笔

- `circle`/`flat` 出硬边实色，`soft` 是实芯带晕边，`watercolor` 给大块氛围和湿边，`splatter` 撒颗粒，`dry` 出飞白。
- 小尺寸 `flat` + 间距 1 + 浓度 75–90，是铅笔线。
- 涂抹可以当手指用：短距离混两色，长距离拖出方向感；贴近轮廓时用小笔头，别把形糊掉。
- 长线可少量加 `jitter`，精确接缝可以用 0。

## 自检

- 先 glance：几块大色块能不能合起来读成你要的东西，焦点是不是跑偏。
- 再看 zoom：一条边、一只眼、一处颜色过渡；有问题就只改那一块。
- 如果一块地方看着"乱"，通常是色太多或细节太碎，不是不够细：收窄颜色、把细节画少一点。形状在这个尺度已经读得出来，就不用再加笔了。

# 笔触参数

一条 `canvas_draw` 的 stroke 可以带这些字段。**越界不会报错**：数值被夹到最近的合法值、坐标被拉回画布边上，回复里会列 "Corrected to a legal value: …"。

| 字段 | 范围 / 取值 | 说明 |
|---|---|---|
| `color` | `#rgb` / `#rrggbb` | 不传就用面板前景色；写错的颜色会被忽略并说明 |
| `size` | 0.5–600 px | 见下面"宽度" |
| `strength` | 1–100 | 颜料浓度：100 满色，20 只是淡淡一层 |
| `wetness` | 0–100 | 边缘扩散：100 会洇，20 收得住。**只影响边缘，不影响深浅** |
| `spacing` | 1–100 % | 印章间距：1 + 小 size + 浓度 75–90 = 铅笔线 |
| `brushType` | `watercolor` `circle` `soft` `flat` `dry` `splatter` | 六个名字拼错会被忽略（用面板当前笔刷） |
| `taper` | `in` / `out` / `both` | 自动写压力坡：1 → 0.3，同时变细变淡 |
| `usePressure` / `pressureCurve` | `linear` `soft` `firm` `ink` | 压感响应曲线；不传压感就没意义 |
| `drip` / `dripAmount` | `auto` `on` `off` / 0–2 | 只有 `watercolor` 且湿度 ≥ 50 才会有水滴；`dripAmount` 是**密度**不是射程 |
| `mirror` | `x` / `y` | 同一笔再镜像一次，左右对称的眼睛、耳朵一笔搞定 |
| `unit` | `pixels` / `ratio` | 默认看量级：值都在 0–1 内（或最多 1.25 以内）按比例读 |
| `jitter` | 0–20 px | 轮廓抖动；`flat` 细线加 0.5–1.5 更像手画 |
| `smooth` | `true` / `false` | 三点以上的开放折线默认圆滑；闭合折线默认保留顶点，`true` 可主动圆滑 |

## 宽度（最容易踩的坑）

- `circle` / `flat` / `soft`：画出来约 **1×size**，不透明。
- `watercolor` / `dry` / `splatter`：约 **2×size**，而且水彩只沉积约一半颜料。
- 所以"铺一层 200px 宽的水彩"要写 `size: 100`，不是 200。

## 坐标

- 画布像素：和 `canvas_look` 报的尺寸一致。
- 比例：所有值都在 0–1 之间就自动按比例读，可以直接从 glance/zoom 上量。想强制就写 `unit`。
- 想"越过边再让画布裁掉"：写 `1.02` 也算比例（带宽到 1.25），会被拉回边上——笔头半径自己会越界，效果一样。

## 路径写法

一条路径最稳的写法是一行字符串：

```
"path": "0.36,0.60 0.37,0.65 0.40,0.70:0.4"     # 空格分词，逗号分坐标，冒号后是压感
"path": "0.30,0.40 q 0.50,0.10 0.70,0.40"        # q = 二次曲线（一个控制点）
"path": "0.20,0.30 c 0.30,0.10 0.50,0.10 0.60,0.30"   # c = 三次曲线（两个控制点）
```

## 形状

不必一行行刷，形状可以直接给：

```
"ellipse": [0.5, 0.33, 0.12, 0.11]                     填一个椭圆（从圆心往外绕的螺旋，边缘干净）
"ellipse": [0.5, 0.33, 0.12, 0.11], "ring": true       只描边，size 变成线宽
"ellipse": [0.5, 0.33, 0.12, 0.11], "from": 200, "to": 340   画一段弧
"polygon": [[0.36,0.52],[0.64,0.52],[0.68,0.74],[0.32,0.74]]  填多边形
"path": "0.2,0.3 q 0.4,0.1 0.6,0.2 l 0.62,0.7 z", "fill": true  闭合并填充的曲线轮廓
"mirror": "x"                                          同一笔再镜像一次
```

`seam` 可以旋转椭圆螺旋的收尾方向，把可能出现的"起笔疙瘩"藏到指定的角度。

需要贴边描线时，可以在同一条 `polygon` 或 `fill: true` 笔触里加 `"outline":{"color":"#53445e","size":2}`。圆头笔沿填色实际使用的轮廓走一遍，尖角、曲线和边缘抖动都能对齐。填色与描边各占一步撤销。需要干净的实色边缘可以用圆头笔；高湿度水彩收笔后仍会自然洇开。

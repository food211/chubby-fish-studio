# 选区（canvas_mask）

在一小块范围内作画——修一只眼睛、给头发加高光、只改某个区域——不用怕画到外面。

## 用法

```json
{ "action": "set", "rect": [0.2, 0.2, 0.7, 0.8], "unit": "ratio", "jitter": 1 }
{ "action": "set", "polygon": [[0.3,0.2],[0.7,0.2],[0.75,0.6],[0.5,0.8],[0.25,0.6]], "jitter": 2 }
{ "action": "status" }
{ "action": "clear" }
```

- `rect` 是 `[x1,y1,x2,y2]` 两个对角点；`polygon` 是 3–48 个顶点。两者只给一个。
- `unit` 不写就按量级判断（都在 0–1 内 = 比例）。
- `jitter` 是边缘抖动（画布像素，0–20，默认 1）。**只在设定那一刻采样一次**，之后画多少笔边界都不变；要精确边缘写 0。
- 顶点越界不会被拒绝，会被拉到画布边上，并在回复里说明拉了几个。

## 行为边界

- **笔刷和涂抹**都被裁到选区内，包括软笔刷的软边——所以修边的时候软刷也不会渗出去。
- 面板上会显示虚线预览；**虚线不会被导出**，`canvas_look` / `glance` / 录制都看不到它。
- **撤销、重做、清空仍然作用于整张画布**。
- 选区一直有效，直到 `clear` 或面板重载。
- `status` 返回当前选区的多边形（比例坐标）和单位。

## 什么时候值得用

- 眼睛、嘴、宝石这类小元素上色，外面已经画好了，不想蹭脏。
- 头发要铺 2~3 层渐变，用发形多边形做选区，宽笔刷就不会糊到脸上。
- 局部返工：只重画一个区域，别的部分保护起来。

## 什么时候别用

- 铺大背景：反而要画满整张，选区只会碍事。
- 需要柔边自然过渡到选区外：硬边会留下看得见的界线，除非你本来就想要一条边。

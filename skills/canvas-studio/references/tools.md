# 工具手册

## 看（三档 + 一档不算看）

| 工具 | 什么时候用 | 开销 |
|---|---|---|
| `canvas_glance` | 默认的第一眼：整张缩成 360px 缩略图，看构图、大色块、脸有没有歪 | 最省 |
| `canvas_zoom` | 一个矩形放大的细节：`from [0.2,0.3]`、`to [0.45,0.55]`，都是 0~1 比例，直接从 glance 上量 | 只付这一块 |
| `canvas_look` | 整张原尺寸 + 画布尺寸、笔刷、调色板、撤销位置。颜色、边缘、验收时用 | 最贵 |
| `canvas_state` | 只读参数（尺寸、笔刷、滑条、历史位置），不传图 | 最便宜，但**不算看过** |

**落笔前的守卫**：`canvas_draw` 会拒绝，直到你在这个会话里看过整张画；上次看过之后画面又变了也会拒绝（用户画了、撤了、清了、面板重载）。被拒之后**先 glance 再重试**，别原样重发。你自己刚落的笔、以及"确认过的清空"不算变化。

## 画

`canvas_draw` 是唯一落笔的工具：`strokes` 数组，每条一个笔触；也带 `action: "undo" | "redo" | "clear"`。字段、范围、形状写法见 `parameters.md`。

- 一次 6~8 笔最稳；越长的调用越容易被流截断，断了整批都白画。
- `undo` 之后画布和你上次看到的不一样了，下一笔之前要再看一次。
- `clear` 会让用户丢掉整张画，不要自己决定清空。

## 选区

`canvas_mask`：矩形或多边形，之后笔刷和涂抹只在这个范围生效。细节见 `selection.md`。

## 录制

`canvas_record`：`start` 在落笔前，`stop` 在画完时；片段落在面板设置里的录制目录并导出。配方见 `recording.md`。

## 按需加载的四个

`canvas_tools` 一次加载一组，加载后从下一步起可用：

| 组 | 工具 | 内容 |
|---|---|---|
| `guide` | `canvas_guide` | 画法：构图、分层、光、收笔、何时重画（纯文字） |
| `brushes` | `canvas_brushes` | 引擎自己画的笔刷样张 + 每支一行说明 |
| `notes` | `canvas_notes` | 共用的画法笔记目录，按篇读 |
| `sample` | `canvas_sample` | 读精确像素色值：`(x, y) → #RRGGBB` |

**只有需要时才加载**：一次画新图，通常 `notes`（看前人的坑）和 `brushes`（确认笔刷手感）各一次就够；`sample` 只在验收关键颜色时用。

## 常见误用

- 拿 `canvas_state` 当"看过了"——它不算，落笔会被拒。
- 为了省一次调用把 20 笔塞进一个 `canvas_draw`——断了全丢。
- 用 `canvas_zoom` 的 `maxWidth` 开到 1200 去看整张画——比 `canvas_look` 还贵，而且没有颜色和笔刷信息。
- 用户刚说"你画的还在吗"，直接 `canvas_look` 而不 `canvas_glance`——先 glance 通常就够回答。

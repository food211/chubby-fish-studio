# 肥鱼画室：画布使用手册

画室里的画布是**你和用户共用**的：Kubelka–Munk 颜料混色，水彩会洇、会堆湿边。你落笔，用户随时撤销；你的每一笔都进同一个撤销栈。

## 什么时候读这份手册

- 用户要你**画一张新画**、**录制过程**、**框一小块来改**，或问"这画布怎么用"：先读这里，再按下面的表挑参考篇。
- 只是补一两笔、改个颜色：不用读，直接 `canvas_draw`。

## 基本节奏

画新作品时，建议先在画布上起一张快稿，给用户看并等反馈。在原草稿上改到用户认可，再留好草稿作参考，从空白画布另画正式稿。具体做法见画法篇。

1. `canvas_glance` 先看（最便宜的一档）；局部细节用 `canvas_zoom`；颜色、边缘真的要紧才 `canvas_look`。
2. `canvas_draw` 小批量落笔——一次 6~8 笔最容易写对，长调用被截断会整批白画。
3. 每 3~5 批 glance 一次，看大形有没有塌、脸有没有歪。
4. 收尾 `canvas_look` 验收，再用 `canvas_sample` 读几个关键像素确认颜色。

## 还有两把"内容型"工具

DSH 通过 `canvas_tools` 加载对应组；独立 MCP 可直接调用工具。

- `canvas_brushes`：引擎自己画的笔刷样张，六支笔的手感一眼对比。**开新画、选笔之前值得看一眼。**
- `canvas_notes`：所有会话共用的画法笔记。新画前看索引，画完把"早一点知道就能省一次重画"的一条追加进去——一条一句，过时的删掉。

## 硬规则（省事版）

- **没看过不能落笔**。画面变了（用户画了、撤了、清了、面板重载了）必须再看一次。
- **白色水彩压不住深色**，只会变灰；要纯白用 `circle`/`flat`/`soft`。反过来 `circle/flat/soft` 做不出湿画的水味。
- **先背景后主体**。主体画上去之后别回头重刷背景，会把主体洗掉。
- **越界不报错**：坐标和参数会被夹到最近的合法值，并在回复里列出夹了什么。
- **重画常常比打补丁快**，但清空是用户的决定，先问。
